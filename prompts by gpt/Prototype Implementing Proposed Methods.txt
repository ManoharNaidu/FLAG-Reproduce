============================================================
0. PROJECT CONTEXT
==================

Read the project initiation report provided by the user before making architectural decisions.

The project is:

"Large Language Models for Graph-Based Fraud Detection"

The project's research direction investigates whether FLAG's semantic-similarity neighbour filtering can be combined with DGP's hierarchical summarization and extended using similarity-weighted metapath pruning.

The proposed framework consists of:

MODULE 1:
Semantic-Similarity Neighbour Filtering

MODULE 2:
Hierarchical / Selective Summarization

MODULE 3:
Metapath-Based Neighbourhood Pruning

The project asks questions around:

RQ1:
How can semantic similarity-based neighbour filtering be combined with hierarchical summarization to improve fraud detection in static financial graphs affected by heterophily?

RQ2:
Does pre-filtering neighbours by semantic similarity before summarization improve detection and provide a better accuracy-to-token trade-off?

RQ3:
Can semantic similarity be used as a weighting mechanism in metapath-based neighbourhood pruning?

The report describes the three modules as sequential/interacting components.

Therefore, the demo must make that sequential relationship visible.

11. MODULE 3 — SEMANTIC-WEIGHTED METAPATH PRUNING
=================================================

Module 3 MUST consume the outputs of Module 1 and Module 2.

Do not recompute semantic similarity separately unless explicitly necessary.

Reuse Module 1's semantic scores.

The project's proposed idea is:

For a path:

P = (v0, v1, ..., vL)

and semantic similarities:

s(v_i, v_{i+1})

compute:

w(P) = product of semantic similarities

Use this as a continuous path influence / pruning weight.

IMPORTANT:

This is the project's proposed extension.

Do NOT claim that FLAG itself implements this mechanism.

Do NOT claim that the project's proposed implementation is an official method.

Label it explicitly as:

PROJECT PROPOSED MODULE 3

or:

DEMO — SEMANTIC-WEIGHTED METAPATH PRUNING
